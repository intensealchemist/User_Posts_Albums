# API Specification — User Posts Albums Explorer

**Version:** 0.1  
**Date:** 2026-10-03  
**Base URL:** `https://jsonplaceholder.typicode.com`

> Refer to the detailed DOCX: [API-Spec_v0.1.docx](./API-Spec_v0.1.docx)

## Endpoints

| # | Method | Endpoint | Description |
|---|--------|----------|-------------|
| 1 | GET | `/users` | Fetch all users |
| 2 | GET | `/users/{id}` | Fetch a single user |
| 3 | GET | `/posts` | Fetch all posts |
| 4 | GET | `/users/{id}/posts` | Fetch posts by user |
| 5 | GET | `/albums` | Fetch all albums |
| 6 | GET | `/users/{id}/albums` | Fetch albums by user |

## Response Format

All responses return JSON.
